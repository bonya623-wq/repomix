# 🎮 goha.ru → Telegram News Bot

Автоматический бот, публикующий новости с goha.ru в Telegram-канал.  
Проверяет новые статьи каждые 5 минут и публикует их в нужном формате.

---

## Как работает

```
goha.ru  ──RSS/HTML──►  Parser  ──new?──►  Storage (JSON)
                                    │
                                    ▼
                             Telegram Channel
```

1. Каждые 5 минут парсер запрашивает goha.ru
2. Сначала ищет RSS-ленту (быстро и надёжно), при отсутствии — парсит HTML
3. Сверяет найденные статьи с базой уже опубликованных (published.json)
4. Новые статьи отправляет в канал в нужном формате, сохраняет в базу

### Формат поста

```
🎮 Заголовок новости

Краткое описание статьи...

📅 19.05.2026 14:30
🔗 Читать полностью → goha.ru
```

## Быстрый старт

### 1. Получить токен бота

1. Напишите [@BotFather](https://t.me/BotFather) → `/newbot`
2. Скопируйте полученный токен

### 2. Подготовить канал

1. Создайте Telegram-канал (публичный: `@your_channel` или приватный)
2. Добавьте бота в канал как **Администратора** с правом публикации
3. Для публичного канала ID = `@your_channel`  
   Для приватного — узнайте числовой ID через [@userinfobot](https://t.me/userinfobot)

### 3. Настройка

```bash
git clone <repo>
cd telegram_news_bot
cp .env.example .env
nano .env   # вставьте BOT_TOKEN и CHANNEL_ID
```

### 4. Запуск (вариант A — Python напрямую)

```bash
pip install -r requirements.txt
python -m telegram_news_bot.main
```

### 5. Запуск (вариант B — Docker, рекомендуется для 24/7)

```bash
mkdir -p data && touch data/published.json data/bot.log
docker-compose up -d
docker-compose logs -f   # следить за логами
```

### Одиночный прогон (cron)

```bash
python -m telegram_news_bot.main --once
```

Пример crontab для проверки каждые 10 минут:
```
*/10 * * * * cd /path/to/bot && python -m telegram_news_bot.main --once >> cron.log 2>&1
```

## Конфигурация (.env)

| Переменная | Описание | По умолчанию |
|---|---|---|
| `BOT_TOKEN` | Токен от @BotFather | **обязательно** |
| `CHANNEL_ID` | `@username` или `-1001234567890` | **обязательно** |
| `CHECK_INTERVAL` | Интервал проверки в секундах | `300` (5 мин) |
| `MAX_ARTICLES_PER_RUN` | Макс. статей за один цикл | `5` |
| `DB_PATH` | Путь к JSON-базе | `published.json` |
| `REQUEST_TIMEOUT` | Тайм-аут HTTP-запросов (сек) | `15` |

## Адаптация под изменения сайта

Если структура HTML на goha.ru изменится, отредактируйте `HTML_SELECTORS` в `parser.py`:

```python
HTML_SELECTORS = {
    "card":        ["article", ".news-item", ...],
    "title":       ["h2", ".title", ...],
    "description": [".description", "p", ...],
    "image":       ["img"],
    "date":        ["time", ".date", ...],
}
```

## 📣 ПЛАН ПРОДВИЖЕНИЯ КАНАЛА

### Фаза 0 — Подготовка (до запуска, 1 неделя)

**Оформление канала:**
- Название: конкретное и запоминаемое, например `Goha.ru | Игровые новости` или `GameFeed 🎮`
- Аватар: узнаваемый, игровая тематика, высокое разрешение (800×800)
- Описание (160 символов): чётко объяснить ЧТО и КАК ЧАСТО публикуется
  - Пример: *«Лучшие игровые новости с goha.ru — автоматически, 24/7. Свежий контент каждые 5 минут»*
- Ссылка на канал: короткая и понятная (`t.me/gohanews`)
- Закреплённый пост: приветственный пост с правилами и тематикой канала

**Контент-план:**
- Убедитесь, что бот стабильно работает 2–3 дня в тестовом режиме
- Накопите 20–30 постов прежде чем начинать активное продвижение
- Новый подписчик должен видеть живой, активный канал

### Фаза 2 — Ускорение роста (1–3 месяц)

#### 2.1 Взаимопиар (ВП) — самый эффективный бесплатный метод
- Найдите Telegram-каналы смежной тематики (аниме, кино, технологии, киберспорт) с аудиторией 500–5000 подписчиков
- Предложите взаимную рекламу: вы публикуете их пост, они — ваш
- Ищите партнёров через [tgstat.ru](https://tgstat.ru) → фильтр по категории «Игры»

Шаблон предложения ВП:
```
Привет! У меня канал @your_channel (игровые новости с goha.ru, 
X подписчиков). Предлагаю взаимопиар. Пиши, если интересно!
```

#### 2.2 Платное продвижение
**Бюджет от 500 ₽:**

| Метод | Цена | Ожидаемый результат |
|---|---|---|
| Реклама в тематических TG-каналах | 500–5000 ₽/пост | 50–500 новых подписчиков |
| Яндекс.Директ на лендинг | от 1000 ₽ | Зависит от CTR |
| VK Реклама (таргет) | от 500 ₽/день | 20–100 подписчиков/день |
| Telegram Ads (официальная реклама) | от 2 € CPM | Масштабируемо |

**Как выбрать канал для рекламы:**
1. Проверьте через [tgstat.ru](https://tgstat.ru): ERR > 10%, прирост не накрученный
2. Тематика: игры, технологии, кино, аниме, молодёжь 16–35 лет
3. Попросите скриншот статистики у администратора

#### 2.3 YouTube / TikTok / Reels
- Создайте короткий контент (30–60 сек) по горячим новостям с goha.ru
- В описании и в конце видео: «Все игровые новости → @your_channel»
- Даже 1–2 видео в неделю дают органический трафик

| Метод | Описание | Доход |

| **Партнёрские ссылки** | Amazon, Яндекс.Маркет (игры, железо) | % от продаж |

- `CPM` = подписчики / 1000 × средний ER%
- Стандарт для игровых каналов: ~50–150 ₽ за 1000 просмотров

## Поддержка и troubleshooting

**Бот не публикует:**
1. Проверьте, что бот — администратор канала с правом на публикацию
2. Запустите `python -m telegram_news_bot.main --once` и смотрите вывод
3. Проверьте логи: `tail -f bot.log`

**Дублирование постов:**
- Удалите или очистите `published.json` (сбросит историю)

**goha.ru изменил структуру:**
- Откройте DevTools → Inspector на goha.ru/news
- Обновите `HTML_SELECTORS` в `parser.py`
